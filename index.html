Centro de notificaciones

En esta versión se registran todos los cambios hechos en este navegador, incluidos los pequeños. La sincronización y los avisos a otros usuarios requieren configurar el servidor privado. No se envían notificaciones push todavía.

Seguridad y configuración

Esta web todavía no tiene inicio de sesión real. Una contraseña solo visual no protegería la información. Para habilitar acceso privado de Miguel, Michelle y Carla necesitamos configurar autenticación, reglas de acceso y almacenamiento en un backend (por ejemplo Supabase). Hasta entonces, utiliza únicamente datos de prueba no sensibles.

Los cambios se guardan localmente en el navegador y no se comparten con otros dispositivos. Puedes descargar una copia de los datos de prueba.

No importes datos de personas reales antes de completar la configuración de seguridad.
